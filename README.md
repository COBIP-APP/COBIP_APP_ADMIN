# COBIA 관리자 웹

문법·실무 챕터와 목차별 학습 내용, 목차별 문제, 앱 하단 메뉴의 독립 문제를 등록하는 관리자 화면입니다. 기존 `COBIP_APP_BE` Spring API와 PostgreSQL을 그대로 사용하며, 별도 DB를 만들지 않습니다.

## 로컬 실행

1. `COBIP_APP_BE`에서 백엔드와 DB를 실행합니다. 예: `docker compose --profile full up -d --build --wait`
2. 이 폴더에서 `npm install`을 실행합니다.
3. `npm run dev`를 실행하고 브라우저에서 `http://127.0.0.1:5174`를 엽니다.
4. `ADMIN` 권한을 가진 기존 COBIA 계정으로 로그인합니다. DB에서 권한을 변경했다면 새로 로그인해야 새 JWT에 반영됩니다.

개발 서버는 `/api` 요청을 `http://localhost:8080`의 Spring 서버로 전달합니다. Spring 서버 주소가 다르면 PowerShell에서 `$env:API_PROXY_TARGET='http://localhost:8081'`을 설정하고 `npm run dev`를 실행하세요. 관리자 로그인 토큰은 브라우저 메모리에만 보관되며 새로고침하면 다시 로그인합니다.

## 콘텐츠 등록 순서

1. **문법 챕터:** 언어 선택 → 챕터 정보 저장 → 목차 `1-1` 등록 → 학습 본문과 예제 코드 저장 → 목차별 문제 등록 및 공개 → 챕터 공개.
2. **실무 챕터:** 원하는 주제가 없으면 **언어 · 주제 → 실무 주제 → + 새 주제**에서 표시 이름·분류 코드·표시 순서를 저장합니다. 그다음 실무 챕터에서 주제를 선택하고 챕터 정보 → 상위 개요 `1` → 하위 목차 `1-1`, `1-2` → 각 하위 목차의 문제 순서로 등록합니다. 상위 개요에는 문제를 연결하지 않습니다.
3. **문제 영역:** 챕터에 속하지 않는 독립 문제를 저장한 뒤 정답을 확인하고 공개합니다.

새 챕터와 문제는 비공개 초안으로 저장됩니다. 앱에 보이게 하려면 각각 **공개** 버튼을 눌러야 합니다. 목차에는 별도의 공개 상태가 없습니다. 문법 목차 `1-1`의 문제는 반드시 해당 목차를 선택하고 등록하세요.

목차의 **학습 본문**은 Markdown 원문으로 저장합니다. 입력창 위의 서식 버튼으로 소제목(`##`), 강조(`**`), 목록(`-`), 인용(`>`), 인라인 코드(백틱)를 넣고 아래 미리보기에서 확인할 수 있습니다. 기존 일반 텍스트도 그대로 저장되며, 예제 코드 입력칸은 별도로 유지합니다. 앱에서 같은 서식을 보이려면 Flutter 학습 화면도 `body`를 Markdown으로 렌더링해야 합니다. HTML과 이미지 삽입은 미리보기에서 지원하지 않습니다.

챕터·목차·문제의 **삭제** 버튼은 백엔드의 관리자 삭제 API를 사용합니다. 챕터 삭제 시 모든 하위 목차와 연결 문제, 목차 삭제 시 하위 목차와 연결 문제가 함께 목록에서 사라집니다. 기존 제출·학습 기록은 DB에 남습니다. 문제 영역의 독립 문제는 최신 등록 순서로 표시합니다. 삭제 기능을 사용하려면 백엔드에 해당 API가 반영되어 있어야 합니다.

코드 작성형 AI 채점은 현재 **Java만** 지원합니다. 목차나 문제의 표시 순서는 같은 범위에서 겹치지 않게 입력해야 합니다. DB의 순서 중복 제약에 걸리면 저장이 실패합니다.

저장이 실패하면 입력 폼 아래의 오류 문구를 확인하세요. 필수 입력란의 공백만 입력한 값과 존재하지 않는 실무 주제는 저장 전에 안내하며, 서버가 반환한 입력 필드와 중복 순서 오류도 표시합니다.

## 배포 참고

`npm run build`로 생성되는 `dist/`를 정적 파일로 제공하고, 같은 도메인의 `/api`를 Spring 백엔드로 프록시해야 합니다. 개발 서버의 Vite 프록시는 배포 빌드에 포함되지 않습니다. 관리자 경로와 백엔드 API 모두 접근 제어를 적용하세요. 이미지 업로드는 아직 지원하지 않습니다.

API 요청·응답 상세는 [백엔드 학습 API 명세](https://github.com/COBIP-APP/COBIP_APP_BE/blob/develop/docs/learning-api.md)와 실행 중인 Swagger UI에서 확인할 수 있습니다.
