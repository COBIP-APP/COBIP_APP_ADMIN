# COBIA 관리자 웹

COBIA 앱에 표시할 학습 콘텐츠를 관리하는 React·Vite 웹 화면입니다. 문법·실무 챕터와 목차, 학습 본문, 문제, 언어와 실무 주제를 등록합니다. [COBIP_APP_BE](https://github.com/COBIP-APP/COBIP_APP_BE)의 API와 DB를 함께 사용하며 관리자 웹만의 DB는 없습니다.

## 할 수 있는 일

| 메뉴 | 작업 |
| --- | --- |
| 문법 챕터 | 언어별 챕터·목차·본문·예제 코드·연결 문제 관리 |
| 실무 챕터 | 실무 주제별 챕터와 상위 개요·하위 목차 관리 |
| 문제 영역 | 챕터에 속하지 않는 독립 문제 관리 |
| 언어 · 주제 | 학습 언어와 실무 주제 등록·표시 순서 관리 |

## 로컬 실행

**필요한 것:** Git, Node.js·npm, 실행 중인 [COBIA 백엔드](https://github.com/COBIP-APP/COBIP_APP_BE). 백엔드 README에 따라 Docker Compose의 `app`, `postgres`, `redis`를 먼저 실행합니다. 그다음 Windows PowerShell에서:

```powershell
git clone --branch develop https://github.com/COBIP-APP/COBIP_APP_ADMIN.git
cd COBIP_APP_ADMIN
npm ci
npm run dev
```

브라우저에서 `http://127.0.0.1:5174`를 엽니다. Vite 개발 서버는 `/api` 요청을 기본적으로 `http://localhost:8080`의 Spring 백엔드로 전달합니다. 백엔드 포트가 다르면 개발 서버를 시작하기 전에 PowerShell에서 다음처럼 설정합니다.

```powershell
$env:API_PROXY_TARGET='http://localhost:8081'
npm run dev
```

**`ADMIN` 권한이 있는 COBIA 계정**으로 로그인해야 합니다. 일반 사용자 계정으로는 관리자 화면을 사용할 수 없습니다. 권한을 변경한 뒤에는 로그아웃하고 새로 로그인해야 새 토큰에 반영됩니다. 관리자 세션은 브라우저 메모리에만 보관되므로 새로고침하면 다시 로그인합니다.

## 콘텐츠를 앱에 보이게 하는 순서

1. **문법:** 언어 선택 → 챕터 기본 정보 저장 → 목차 추가 → 각 목차의 본문·예제 코드 작성 → 목차별 문제 추가 → 문제 공개 → 챕터 공개.
2. **실무:** 필요하면 `언어 · 주제` 메뉴에서 실무 주제 등록 → 실무 챕터 생성 → 상위 개요와 하위 목차 작성 → 하위 목차의 문제 등록·공개 → 챕터 공개.
3. **독립 문제:** `문제 영역`에서 문제·정답·해설을 입력하고 공개.

새 챕터와 문제는 **비공개 초안**으로 저장됩니다. 앱 목록에 보이지 않는다면 챕터와 해당 문제의 공개 상태를 각각 확인합니다. 목차는 별도의 공개 상태가 없습니다. 목차별 문제를 만들 때는 해당 목차를 먼저 선택합니다.

학습 본문은 Markdown으로 작성하고 입력 화면에서 미리 볼 수 있습니다. `##` 소제목, `**강조**`, 목록, 인용, 인라인 코드를 사용할 수 있습니다. 예제 코드는 별도 입력칸에 작성합니다. 현재 이미지 업로드와 본문 HTML 삽입은 지원하지 않습니다.

## 자주 확인할 점

- **로그인 실패 또는 401:** 백엔드 실행 여부와 계정의 `ADMIN` 권한을 확인한 뒤 다시 로그인합니다.
- **저장은 됐는데 앱에 안 보임:** 챕터·문제의 공개 상태와 앱이 접속하는 백엔드/DB를 확인합니다. 로컬 DB와 운영 DB의 콘텐츠는 자동으로 공유되지 않습니다.
- **저장 실패:** 필수 입력값, 같은 범위의 표시 순서 중복, 화면 아래의 서버 오류 메시지를 확인합니다.
- **5174 포트 사용 중:** 기존 관리자 개발 서버를 종료하고 다시 실행합니다. 이 프로젝트는 Vite의 5174 포트를 사용합니다.

## 빌드와 API

```powershell
npm run build
```

결과물은 `dist/`에 생성됩니다. 이 정적 파일을 배포할 때는 배포 환경에서 `/api`를 Spring 백엔드로 연결해야 합니다. Vite 개발 프록시는 빌드 결과에 포함되지 않습니다. API 목록은 [백엔드 학습·관리자 API 문서](https://github.com/COBIP-APP/COBIP_APP_BE/blob/develop/docs/learning-api.md)와 실행 중인 Swagger UI에서 확인할 수 있습니다.
